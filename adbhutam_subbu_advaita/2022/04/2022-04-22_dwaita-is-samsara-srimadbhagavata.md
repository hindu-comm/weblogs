Dwaita is samsara – Srimadbhagavata

Bondage and liberation–not real

श्रीमद्भागवतपुराणम्/स्कन्धः७/अध्यायः१३

[https://sa.wikisource.org/s/bn5](https://sa.wikisource.org/s/bn5)

``` wp-block-preformatted In this chapter, here are the words of the enlightened man: ```

``` wp-block-preformatted
तत्रापि दम्पतीनां च सुखायान्यापनुत्तये ```

``` wp-block-preformatted कर्माणि कुर्वतां दृष्ट्वा निवृत्तोऽस्मि विपर्ययम् २५ सुखमस्यात्मनो रूपं सर्वेहोपरतिस्तनुः मनःसंस्पर्शजान्दृष्ट्वा भोगान्स्वप्स्यामि संविशन् २६ इत्येतदात्मनः स्वार्थं सन्तं विस्मृत्य वै पुमान् विचित्रामसति द्वैते घोरामाप्नोति संसृतिम् २७ ```

``` wp-block-preformatted Man strives for worldly pleasures. Due to this, the samsara (again and again) bears the unreal duality. It is a verbatim validation of the Kathopanishad passage - मृत्योः स मृत्युमाप्नोति य इह नानेव पश्यति – He who perceives difference as real ends up in repeated birth and death, samsara. 
```

``` wp-block-preformatted
In this chapter, the sage says: ```

``` wp-block-preformatted
सुप्तिप्रबोधयोः सन्धावात्मनो गतिमात्मदृक् ```

``` wp-block-preformatted पश्यन्बन्धं च मोक्षं च मायामात्रं न वस्तुतः ५ ```

``` wp-block-preformatted Bondage, bandha, and liberation, moksha, are not real- they are Mayamatram, nothing but a mere appearance. It is noteworthy that the word 'Mayamatram' is explained by the verse itself: ‘not real’. 
```

``` wp-block-preformatted
This is the restatement of the well-known verse of the Mandukya: ```

``` wp-block-preformatted
प्रपञ्चो यदि विद्येत निवर्तेत न संशयः । ```

मायामात्रमिदंद्वैतमद्वैतंपरमार्थतः॥१७॥

``` wp-block-preformatted [17 If the phenomenal universe were real, then certainly it would disappear. The universe of duality which is cognized is mere illusion (maya); Non-duality alone is the Supreme Reality.]
```
