In the Bharatamanjari, a condensation of the Mahabharata in his own words, Kshemendra has penned verses describing various events of the MB. Here are a few examples where the term ‘Trimurti’ is applicable to both Vishnu and Shiva in different instances:  
 Bharatamanjari   
[http://www.sanskrit-linguistics.org/dcs/index.php?contents=texte&PhraseID=551326](http://www.sanskrit-linguistics.org/dcs/index.php?contents=texte&PhraseID=551326)  
Here Trimurti is Vishnu:

papraccha pāṇḍuputrāṇāṃ duḥkhito jayakāraṇam // (317.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=551318)tamabravīcchāntanavo rājannukto ‘si sarvadā / (318.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=551319)devena viṣṇunā guptā na jeyāḥ pāṇḍavā iti // (318.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=551320)purā bhūbhāraśāntyarthaṃ svayaṃbhūrmunisaṃsadi / (319.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=551321)prādurbhūtaṃ svayaṃ viṣṇuṃ tuṣṭāva sahasāṃ nidhim // (319.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=551322)jaya viśveśa viśvātmanviśvaksena sudhānidhe / (320.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=551323)amandaciddhanānanda saṃvitsamarasadyute // (320.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=551324)namastubhyaṃ jagatsargasthitisaṃhārakāriṇe / (321.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=551325)trivikramāya mahate triguṇāya trimūrtaye // (321.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=551326)

[http://www.sanskrit-linguistics.org/dcs/index.php?contents=texte&PhraseID=552208](http://www.sanskrit-linguistics.org/dcs/index.php?contents=texte&PhraseID=552208)

Here Trimurti is Shiva: Arjuna’s stuti:

  
bhaktyā tuṣṭāva varadaṃ vareṇyaṃ harṣanirbharaḥ // (260.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=552201)namo bhavāya bhuvanaprabhavāpyāyakāriṇe / (261.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=552202)namaḥ śarvāya niḥśeṣaduṣkarmaviṣahāriṇe // (261.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=552203)namo rudrāya daityendradrāvitendrabhayacchide / (262.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=552204)namaḥ śivāya bhīmāya śrīkaṇṭhāya kapāline // (262.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=552205)ugrāya śreyasāṃ dhāmne vāmārdhāyordhvaretase / (263.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=552206)vyālākulāya sevyāya niṣkalāya kalābhṛte // (263.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=552207)triguṇāya trinetrāya tryambakāya trimūrtaye / (264.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=552208)saṃkalpakalpavṛkṣāya namastubhyaṃ triśūline // (264.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=552209)  
[http://www.sanskrit-linguistics.org/dcs/index.php?contents=texte&PhraseID=557256](http://www.sanskrit-linguistics.org/dcs/index.php?contents=texte&PhraseID=557256)

Here Shiva is Trimurti, Upamanyu stuti:  
śaśāṅkaśakalottaṃsa śiva śānta maheśvara // (1370.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=557254)namastubhyaṃ jagatsargasthitisaṃhārakāriṇe / (1371.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=557255)brahmopendrendravapuṣe triguṇāya trimūrtaye // (1371.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=557256)iti stutipadairdivyairvedaproktaiśca nāmabhiḥ / (1372.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=557257)sahasrasaṃkhyaiḥ sa munistuṣṭāva śaśiśekharam // (1372.2)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=557258)evamīśvarasambaddhāḥ kṛtvāhaṃ muninā kathāḥ / (1373.1)[Par.?](http://www.sanskrit-linguistics.org/dcs/index.php?contents=find_parallels&sen_id=557259)  
In the above stuti of Upamanyu, the Shiva Sahasranama of the Mahabharata is what is alluded to by Kshemendra. The names are ‘vedaprokta’ (stated in the Veda, like Sri Rudra prashna) says the text. This word
brahmopendrendra-vapuṣe of the above text reminds us of the Atharvashikhopanishat:ब्रह्मविष्णुरुद्रेन्द्रास्ते सम्प्रसूयन्ते \[Brahma, Upendra (Vishnu), Rudra and Indra are all born of the (Turiya) Shiva.\]  
Om Tat Sat
